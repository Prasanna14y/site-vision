SITE VISION — INSTALL PHOTOS

Drop real photos of your installs into this folder, named like this
(any of .jpg .jpeg .png .heic .webp is fine — phone photos are OK):

  hero.jpg          Home page, top — your best shot (a camera on a building)
  residential.jpg   Industries page — a home install
  commercial.jpg    Industries page — a shop / office / warehouse install
  construction.jpg  Industries page — a construction-site camera
  farm.jpg          Industries page — a farm / rural install
  solar-cam.jpg     Solar Cam page — a solar camera on its pole

Tips: landscape (sideways) photos work best. Daylight or dusk. No customer
faces, house numbers or number plates visible.

Any photo you don't add keeps the current styled "camera feed" panel.
